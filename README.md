# 좀비바이러스 연구실 · 확률과 통계 방탈출

2094년, Z-Virus로 봉쇄된 연구동 지하에서 수학 자물쇠를 풀고 해독제를 완성해 탈출하는 **고등 확률과 통계 웹 방탈출**입니다.

- 2022 개정 교육과정 기준 7구역 28문항 (경우의 수 · 확률 · 통계)
- 구역마다 문 여는 장치가 달라요: 열쇠 · 키패드 · 배전반 · 시료병 순서 · 정전과 절단기 · 그래프 레버 · 해독제 합성
- 휴대폰·태블릿·PC 브라우저에서 바로 실행 (설치·회원가입 없음)
- 교사 설정: 차시 나누기(2·3차시), 문항 켜기/끄기·값 바꾸기, 힌트 대기·페널티, 순위표·CSV

> 배경·인물 그림은 AI 이미지 생성 도구로 만들었습니다.

## GitHub Pages로 올리는 방법 (git 설치 없이, 웹에서만)

1. GitHub에 로그인 → 오른쪽 위 **+** → **New repository**
   - Repository name: 예) `zvirus-escape` (영어·숫자·하이픈만 쓰면 주소가 깔끔해요)
   - **Public** 선택 (무료 계정은 Public 저장소만 Pages를 쓸 수 있어요) → **Create repository**
2. 만들어진 저장소 화면에서 **uploading an existing file** 을 누름
3. 이 폴더를 열고 **폴더 안의 내용 전부**(`img`, `js`, `media` 폴더와 `index.html`, `sw.js`, `.nojekyll` 등)를 선택해 끌어다 놓기
   - ⚠ 폴더 자체가 아니라 **안의 내용**을 올려야 `index.html`이 저장소 맨 위에 놓여요
   - 업로드가 끝나면 아래 **Commit changes** 클릭
4. 저장소 **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)** → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 주소가 떠요: `https://아이디.github.io/zvirus-escape/`

### 다음 차수로 바꿀 때
같은 저장소에서 **Add file → Upload files** 로 새 차수 폴더의 내용을 다시 끌어다 놓고 Commit 하면 돼요 (같은 이름 파일은 덮어써짐).
**저장소와 주소를 그대로 유지해야 학생 기록이 이어집니다.**

## 알아 두기

- 학생 기록은 서버가 아니라 **학생 기기의 브라우저**에 저장돼요. 주소(사이트)가 바뀌면 기록이 이어지지 않아요.
- 학생이 각자 휴대폰으로 했다면 끝난 뒤 **[내 기록 CSV]** 를 받아 모으면 순위를 매길 수 있어요.
- 교사 설정 PIN은 처음 쓸 때 꼭 바꿔 주세요.
- 아이폰은 무음 스위치가 켜져 있으면 소리가 나지 않아요.
- `.nojekyll` 파일은 GitHub Pages가 파일을 그대로 내보내도록 하는 빈 파일이에요. 지우지 마세요.
